# CommonUI & Input Architecture

## 문제와 기존 구조

기존 UMG 상점은 Controller의 입력 모드 전환과 위젯의 구매·복제 이벤트를 함께 사용했다. 개인 후속 리팩터링에서는 상품 그리드와 원래 Blueprint 연출을 재사용하고 화면 활성화와 모달 포커스를 CommonUI로 연결했다.

## 화면 계층과 선택 이유

UShopLayer가 UCommonActivatableWidgetStack을 소유하고 UShopScreen이 WBP_MatchMap_ShopUI를 담는다. UShopConfirmation은 별도 Activatable 항목이다. 한 화면을 닫으면 하위 화면과 이전 버튼 포커스로 복귀한다. 게임 조작 중 상시 표시되는 HUD는 기존 UMG와 모델 구독으로 유지했다.

메뉴 활성화와 화면 수명은 CommonUI, 실제 구매 판정은 서버, 상품 클릭의 단순 전달은 기존 Blueprint가 담당한다. 이름의 접두사·접미사를 해석하던 버튼 분류는 명시적인 버튼 바인딩으로 바꿨다. Focusable 속성은 에디터에서 편집한다.

## 시작·유지·종료 입력

UAgentInputComponent는 상점 중 Move·Look·Fire·Skill·Weapon Switch의 새 동작을 차단한다. 메뉴 진입 시 ReleaseGameplayInput이 진행 중인 발사·점프·앉기·걷기·스파이크 입력을 정리한다. 종료 이벤트는 기존 상태를 해제할 수 있다. Controller는 게임 입력 복귀 시 눌린 키를 비운다.

이 선택은 UI 입력을 막는 것과 이미 시작된 게임플레이를 끝내는 것을 각각 처리하기 위한 것이다. 메뉴 안에서 키를 누르고 닫거나 발사 중 상점을 여는 경우를 따로 검사한다.
